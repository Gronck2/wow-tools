WoW Tools

A small Windows tray app for World of Warcraft that keeps your settings and addons safe: backups after every session, one-click restore, addon updates while you are not playing, and UI profiles you can put on any character.

Download for Windows Source on GitHub

winget install Gronck2.WoWTools

What it does

It runs in the tray and does its work when the game is closed. Every version of the game you have installed is covered: Retail, Classic, Classic Era, Anniversary, PTR and beta.

01

Backups

WTF (bindings, macros, chat, CVars, addon settings) and Interface\AddOns — after every game session or on a schedule.

02

One-click restore

Back to any earlier point. The current state is saved first, so a restore can always be undone.

03

Addon updates

Through the manager you already use — CurseForge, WowUp, WowUp-CF or the Wago App — without a window, on a schedule, never while you play. ElvUI straight from its official site.

04

Game patches

When Battle.net patches the game, settings and addons are saved before the first start on the new version, and you see which addons are not made for it yet.

05

UI profiles

Save a character's interface — bindings, macros, layout, addons and their profiles — and put it on another character in two clicks.

06

Copy between characters

Bindings, macros, chat windows, frame layout, enabled addons and addon settings from one character to others.

07

Cleanup

Settings of removed addons, WoW's .bak copies, old combat logs, screenshots and the cache — with sizes, in one click.

08

Updates itself

Checks GitHub once a day and installs a new version in one click. Each download is checked against its SHA-256.

09

Five languages

English, Russian, German, French and Spanish. Follows the Windows light or dark theme and accent colour.

A look inside

Left click on the tray icon opens the panel, right click the menu.

Privacy and safety

ℹTwo network requests, nothing about you. GitHub once a day for a new version of WoW Tools (can be switched off), and tukui.org for ElvUI when it is installed.
ℹNever touches the game. It does not read game memory and does not automate anything in game.
ℹA snapshot comes first. Whatever changes settings or addons — restore, copying, cleanup, profiles, addon updates — saves the current state before it starts.

Questions

What do I need?

Windows 10 or 11, 64-bit, and World of Warcraft installed through Battle.net. For addon updates — one of CurseForge, WowUp, WowUp-CF or the Wago App, set up. Backups, restore and copying work without them.

Can several addon programs be used at once?

No, on purpose: two managers over one AddOns folder break each other's addons. WoW Tools works with the one you choose.

Copied bindings disappeared after login.

Bindings and macros may be synchronised with the server, which can override copied files. The README shows how to switch that off.

Where does it find the game?

The registry, Battle.net's install list, then the usual paths. Game versions installed in other folders are found too; otherwise set the folder in Settings → General.

Is it free?

Yes. Open source under MIT or Apache-2.0, no ads, no accounts.
